바 차트의 Y축만 고정하고 싶다면, 해당 Y축의 min과 max를 명시적으로 고정해주면 됩니다. 그러면 선 차트(주축)의 Y축은 데이터에 따라 동적으로 변하더라도, 바 차트(보조축)의 Y축은 사용자가 정한 범위 밖으로 튀지 않습니다.

코드 설정 예시

yAxis: [
  {
    type: 'value',
    name: '주축 (선 차트)',
    // min, max를 생략하거나 'auto'로 두면 데이터 변화에 따라 늘고 쥼
  },
  {
    type: 'value',
    name: '보조축 (바 차트)',
    // 바 차트만 범위를 고정
    min: 0,
    max: 100, // 여기에 원하는 고정 최대값을 넣으세요
    interval: 20, // 눈금 간격을 고정하면 더 안정적입니다.
    splitLine: { show: false } // 보조축의 그리드 선이 너무 많으면 끄기도 합니다.
  }
],
series: [
  {
    type: 'line',
    yAxisIndex: 0, // 0번 Y축 참조
    data: [...]
  },
  {
    type: 'bar',
    yAxisIndex: 1, // 1번 Y축 참조 (고정된 0~100 범위 사용)
    data: [...]
  }
]

이 설정의 효과

1. 줌인/줌아웃 시: X축은 동기화되어 같이 움직입니다.
2. 선 차트: 줌인되는 구간의 데이터에 맞춰 Y축 스케일이 자동으로 예쁘게 변합니다.
3. 바 차트: 아무리 줌을 하거나 레전드를 토글해도 Y축 범위는 0 ~ 100으로 철저히 고정됩니다. 막대가 너무 작아지거나 커지지 않아 바 차트의 형태를 일관되게 유지할 수 있습니다.

추가 팁: "고정 최대값이 가변적이어야 한다면?"

만약 max 값을 고정해두고 싶은데, 나중에 데이터가 100을 넘을 수도 있다면 max에 null을 넣어보세요.

- min: 0 (고정)
- max: null (데이터 중 최댓값에 따라 자동 조절되되, 줌을 해도 축이 심하게 덜컥거리지 않게 함)

하지만 완벽하게 고정을 원하신다면 위와 같이 min: 0, max: 100처럼 숫자를 박아두는 것이 가장 확실합니다. 이렇게 적용하면 원하시는 "바 차트 보조축 고정" 기능이 완성됩니다!
